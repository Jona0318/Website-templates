# Éclat — design-forward concept-store Shopify theme

A Shopify **Online Store 2.0** theme, ready to import as a `.zip`. A contemporary,
kinetic design system: gallery-white & electric ultramarine, a sharp hairline
grid, zero corner-radius and no drop-shadows. A tight grotesk display
(**Space Grotesk**) paired with a humanist grotesk body (**Manrope**) and
monospaced micro-labels (**Space Mono**). Accent `#1F2AFF` on `#F1F1EE`.

Built to sell: a bold oversized-type hero, a kinetic marquee, a department
lookbook, a clean four-up "New Arrivals" grid, an editorial statement, a studio
feature, a trust bar, and full product / collection / cart / search / blog
templates.

## Import into Shopify

1. Download `downloads/eclat-shopify-theme.zip`.
2. In Shopify admin: **Online Store → Themes**.
3. **Add theme → Upload zip file**, pick the zip.
4. **Customize** your logo, menus, hero image and lookbook tiles.
5. **Publish**.

> The zip already has the correct root structure, so Shopify accepts it directly.
> The brand fonts are loaded by the theme stylesheet, so the type is consistent
> out of the box — change the palette under **Theme settings → Colors**.
