# Klei — keramiek Shopify theme

A Shopify **Online Store 2.0** theme, ready to import as a `.zip`. Accent colour `#B5562E`. Built to sell products: hero, featured collection, product/collection/cart pages, blog, search and more.

## Import into Shopify

1. Download `downloads/klei-shopify-theme.zip`.
2. In Shopify admin: **Online Store → Themes**.
3. **Add theme → Upload zip file**, pick the zip.
4. **Customize** your logo, menus and hero image.
5. **Publish**.

> The zip already has the correct root structure, so Shopify accepts it directly.

## Customize

Colours and fonts are theme settings (**Customize → Theme settings**). Accent default: `#B5562E`, background `#EFE9DF`.
