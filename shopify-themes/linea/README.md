# Linea — editorial concept-store Shopify theme

A Shopify **Online Store 2.0** theme, ready to import as a `.zip`. A quiet-luxury,
editorial design system: paper & ink, a hairline grid, zero corner-radius and no
drop-shadows. High-contrast serif display (**Fraunces**) paired with a grotesk
body (**Inter**) and monospaced micro-labels (**Space Mono**). Accent `#9A3B2C`.

Built to sell: an asymmetric split hero, a slow marquee, a staggered "Edit"
product grid, editorial statement + manifesto sections, a category lookbook, and
full product / collection / cart / search / blog templates.

## Import into Shopify

1. Download `downloads/linea-shopify-theme.zip`.
2. In Shopify admin: **Online Store → Themes**.
3. **Add theme → Upload zip file**, pick the zip.
4. **Customize** your logo, menus, hero image and lookbook tiles.
5. **Publish**.

> The zip already has the correct root structure, so Shopify accepts it directly.
> The brand fonts are loaded by the theme stylesheet, so the type is consistent
> out of the box — change the palette under **Theme settings → Colors**.
