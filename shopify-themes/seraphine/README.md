# Séraphine — warm ivory couture-atelier Shopify theme

A Shopify **Online Store 2.0** theme, ready to import as a `.zip`. A quiet-luxury
atelier design system: warm bone & emerald, a hairline grid, generous air and no
drop-shadows. A refined roman serif display (**Marcellus**) paired with a
humanist grotesk body (**Outfit**) and monospaced micro-labels (**Space Mono**).
Accent `#1F5641` on bone `#F4EFE7`.

Built to sell: an editorial split hero, a refined promise bar, a staggered
"Collection" product grid, a savoir-faire statement, an atelier feature, a
category lookbook, a manifesto, and full product / collection / cart / search /
blog templates.

## Import into Shopify

1. Download `downloads/seraphine-shopify-theme.zip`.
2. In Shopify admin: **Online Store → Themes**.
3. **Add theme → Upload zip file**, pick the zip.
4. **Customize** your logo, menus, hero image and lookbook tiles.
5. **Publish**.

> The zip already has the correct root structure, so Shopify accepts it directly.
> The brand fonts are loaded by the theme stylesheet, so the type is consistent
> out of the box — change the palette under **Theme settings → Colors**.
