# Vesper — dark gilded couture-house Shopify theme

A Shopify **Online Store 2.0** theme, ready to import as a `.zip`. An after-dark
luxury design system: ink & gold, a hairline grid, zero corner-radius and no
drop-shadows. A high-contrast didone serif display (**Cormorant Garamond**)
paired with a geometric grotesk body (**Jost**) and monospaced micro-labels
(**Space Mono**). Accent `#C9A24B` on near-black `#0E0D10`.

Built to sell: a luminous split hero, a slow gilded marquee, a staggered "Maison
Edit" product grid, an atelier feature, an editorial statement + manifesto, a
collections lookbook, and full product / collection / cart / search / blog
templates.

## Import into Shopify

1. Download `downloads/vesper-shopify-theme.zip`.
2. In Shopify admin: **Online Store → Themes**.
3. **Add theme → Upload zip file**, pick the zip.
4. **Customize** your logo, menus, hero image and lookbook tiles.
5. **Publish**.

> The zip already has the correct root structure, so Shopify accepts it directly.
> The brand fonts are loaded by the theme stylesheet, so the type is consistent
> out of the box — change the palette under **Theme settings → Colors**.
