# DE LICHTBAK — filmhuis

Cinematisch poster-editorial arthouse filmhuis in antraciet × ivoor × marigold: Archivo Black/Bebas posterkoppen, filmkorrel, programma met speeltijden + genre-filter, lidmaatschap en reserveerformulier.

- **Tier:** Premium
- **Sector:** Cultuur
- **Sfeer:** donker
- **Lettertypen:** Archivo Black, Bebas Neue, DM Sans, Space Mono
- **Technieken:** film-grain, program-schedule, genre-filter, category-filter, membership, reservation-form, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
