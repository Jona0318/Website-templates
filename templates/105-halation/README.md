# HALATION | spatial light atelier

Cinematisch donker lichtatelier in grafiet x koud mint: Syne-display, scene-console met drie lichtmodi, hover-preview voor diensten, editoriale case-sectie en een strakke briefing-form.

- **Tier:** Signature
- **Sector:** Interieur
- **Sfeer:** donker
- **Lettertypen:** Syne, Manrope, IBM Plex Mono
- **Technieken:** scene-presets, hover-preview, ambient-pointer-light, contact-form, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
