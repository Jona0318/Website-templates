# AURELIA Systems | AI product studio

High-end dark signature-template voor een AI-productstudio. De site heeft een eigen canvas-engine, een interactieve Signal Atlas, premium glass/hardware layout, cases, proces en een gevalideerd briefingformulier.

- **Tier:** Signature
- **Sector:** Tech
- **Sfeer:** dark
- **Lettertypen:** Geist, Geist Mono
- **Technieken:** signal-atlas-canvas, interactive-modes, complexity-slider, reveal-system, contact-form, form-validate, fullscreen-menu, responsive-images

## Gebruiken

Open `index.html` rechtstreeks in je browser. Er zijn geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
