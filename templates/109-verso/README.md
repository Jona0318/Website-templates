# Verso

Narrative-analytics landing met een scroll-gekoppeld "data wordt tekst"-moment: metrics lossen woord-voor-woord op in een geschreven briefing.

- **Tier:** Signature
- **Sector:** Tech
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Hanken Grotesk, JetBrains Mono
- **Technieken:** scroll-narrative, data-to-text, sparkline-svg, magnetic-cta, faq-accordion, fullscreen-menu, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
