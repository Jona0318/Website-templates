# Kindred - relatie-companion

Warm-editoriale SaaS-landing in royal blue x powder blush: levende warmtekaart waar relaties afkoelen en via een zacht zetje weer opwarmen.

- **Tier:** Signature
- **Sector:** Tech
- **Sfeer:** licht
- **Lettertypen:** Newsreader, Albert Sans
- **Technieken:** warmth-map-svg, scroll-heat-transition, hover-rewarm, faq-accordion, mobile-menu, reveal-system, anim-opt-in, reduced-motion-fallback

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
