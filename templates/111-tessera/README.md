# Tessera - tegelatelier

Keramisch wandatelier met een interactieve mozaiekwand: kies ruimte, patroon en palet en zie direct een proefvlak ontstaan.

- **Tier:** Signature
- **Sector:** Interieur
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Manrope
- **Technieken:** mosaic-composer, palette-picker, pattern-switcher, room-switcher, faq-accordion, mobile-menu, reveal-system, anim-opt-in, reduced-motion-fallback

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
