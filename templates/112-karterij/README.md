# Karterij Noord - routeatelier

Kaartenwinkel met interactief topografisch routepaneel: kies terrein, tempo en kaartstijl en zie de route direct mee veranderen.

- **Tier:** Signature
- **Sector:** Reizen
- **Sfeer:** licht
- **Lettertypen:** Literata, Bricolage Grotesque
- **Technieken:** route-map-svg, terrain-switcher, pace-switcher, style-switcher, faq-accordion, mobile-menu, reveal-system, anim-opt-in, reduced-motion-fallback

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
