# Aurum — premium Shopify-thema

Direct importeerbaar Shopify-thema in zwart × goud (#C89B3C): nette hero, uitgelichte producten, atelier-sectie, nieuwsbrief en footer. Online Store 2.0 (Liquid), upload-klare zip.

- **Tier:** Premium
- **Sector:** Retail
- **Sfeer:** donker
- **Lettertypen:** Playfair Display, Assistant
- **Technieken:** shopify-os2.0, liquid-sections, theme-settings, product-grid, cart, newsletter

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
