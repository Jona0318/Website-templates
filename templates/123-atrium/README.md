# Atrium — architectuur & interieur

Verfijnd Swiss-grid architectuurbureau in wit × zwart × terracotta: zichtbaar raster, hairlines, oversized sectienummers en projectenindex.

- **Tier:** Editorieel
- **Sector:** Interieur
- **Sfeer:** licht
- **Lettertypen:** Archivo, Inter
- **Technieken:** swiss-grid, oversized-numbers, project-index, werkwijze-steps, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
