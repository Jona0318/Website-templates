# Dapper — speelgoed Shopify-thema

Importeerbaar Shopify speelgoed-thema in vrolijke kleuren: speelse hero, speelgoed-grid met leeftijdsbadges, atelier-sectie, nieuwsbrief en footer. Online Store 2.0 (Liquid), upload-klare zip.

- **Tier:** Premium
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Baloo 2, Nunito
- **Technieken:** shopify-os2.0, liquid-sections, theme-settings, product-grid, cart, newsletter

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
