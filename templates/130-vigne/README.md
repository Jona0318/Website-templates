# Vigne — wijn Shopify-thema

Importeerbaar Shopify wijn-thema in bordeaux × crème: sfeervolle hero, flessen-grid met proefnotities, kelder-sectie, nieuwsbrief en footer. Online Store 2.0 (Liquid), upload-klare zip.

- **Tier:** Premium
- **Sector:** Retail
- **Sfeer:** donker
- **Lettertypen:** Cormorant Garamond, Jost
- **Technieken:** shopify-os2.0, liquid-sections, theme-settings, product-grid, cart, newsletter

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
