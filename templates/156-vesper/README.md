# Vesper — luxe couture-huis Shopify-thema

After-dark luxe: ink × champagne-goud, didone Cormorant Garamond en een luminous spotlight-hero. Gilded productgrid, atelier en collecties-lookbook. Importeerbaar Online Store 2.0-thema (Liquid).

- **Tier:** Premium
- **Sector:** Retail
- **Sfeer:** donker
- **Lettertypen:** Cormorant Garamond, Jost, Space Mono
- **Technieken:** shopify-os2.0, liquid-sections, theme-settings, product-grid, cart, newsletter, marquee, reveal-on-scroll

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
