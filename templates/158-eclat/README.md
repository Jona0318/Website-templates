# Éclat — design-concept-store Shopify-thema

Design-forward: gallery-wit × electric ultramarijn met Space Grotesk en een oversized-type hero. Kinetische marquee, horizontale drop-strip en vier-koloms productgrid. Importeerbaar Online Store 2.0-thema (Liquid).

- **Tier:** Premium
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Space Grotesk, Manrope, Space Mono
- **Technieken:** shopify-os2.0, liquid-sections, theme-settings, product-grid, cart, newsletter, marquee, lookbook, horizontal-scroll, reveal-on-scroll

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
