# ZZP Metselaar

Blueprint-stijl met zelftekenende troffel, voor/na-slider en projectfilter.

- **Tier:** Premium
- **Sector:** Diensten
- **Sfeer:** donker
- **Lettertypen:** Archivo, Inter, IBM Plex Mono
- **Technieken:** self-drawing-svg, before-after-slider, category-filter, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
