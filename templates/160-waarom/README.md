# Waarom — strategisch adviseur

Persoonlijke merk-site rond de Golden Circle: een interactieve canvas-cirkel (wat/hoe/waarom) die met de scroll meebeweegt, plus volledige NL/EN-taalwissel.

- **Tier:** Signature
- **Sector:** Advies
- **Sfeer:** donker
- **Lettertypen:** Fraunces, Manrope, Space Mono
- **Technieken:** canvas-golden-circle, scroll-linked-storytelling, language-toggle, sticky-header, mobile-menu, reveal-system, scroll-progress, countup, drawing-timeline, dot-nav, contact-form, reduced-motion-fallback

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
