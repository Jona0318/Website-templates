# Klaarte — merkstrateeg

Licht-redactionele Golden Circle-site: verfijnde canvas-cirkel met dunne inkt/goud-lijnen, warm papier en subtiel goud. Volledige NL/EN-taalwissel.

- **Tier:** Signature
- **Sector:** Advies
- **Sfeer:** licht
- **Lettertypen:** Newsreader, Inter, Space Mono
- **Technieken:** canvas-golden-circle, scroll-linked-storytelling, language-toggle, sticky-header, mobile-menu, reveal-system, scroll-progress, countup, dot-nav, contact-form, reduced-motion-fallback

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
