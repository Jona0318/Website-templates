# Kern — strateeg & merkbouwer

Bold-grafische Golden Circle-site: platte dikke canvas-ringen, crème + hard-zwart met gouden accentblokken, marquee-ticker en hard-shadow kaarten. Volledige NL/EN-taalwissel.

- **Tier:** Signature
- **Sector:** Advies
- **Sfeer:** licht
- **Lettertypen:** Archivo, Inter, Space Mono
- **Technieken:** canvas-golden-circle, scroll-linked-storytelling, language-toggle, marquee, sticky-header, mobile-menu, reveal-system, scroll-progress, countup, dot-nav, contact-form, reduced-motion-fallback

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
