# Essentie — puur inhoud

Content-first leespagina: geen canvas of graphics, alleen mooie typografie. De Golden Circle als tekst, Spectral-serif, hairline-regels en subtiel goud. Volledige NL/EN-taalwissel.

- **Tier:** Editorieel
- **Sector:** Advies
- **Sfeer:** licht
- **Lettertypen:** Spectral, Space Mono
- **Technieken:** language-toggle, scroll-spy, sticky-header, reduced-motion-safe, no-canvas, content-first

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
