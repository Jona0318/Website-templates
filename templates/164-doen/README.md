# Doen — persoonlijke business-site

CV-stramien mét een verhaal: hero-band, sticky sidebar, ervaring-tijdlijn met VERKOCHT-badges en een scroll-gestuurde Golden Circle-reis in tien stappen. Actieknoppen-contact en volledige NL/EN-taalwissel.

- **Tier:** Maatwerk
- **Sector:** Persoonlijk
- **Sfeer:** licht
- **Lettertypen:** Sora, Instrument Sans, Space Mono
- **Technieken:** language-toggle, scroll-linked-storytelling, dot-nav, sticky-sidebar, scroll-spy, sticky-header, mobile-menu, reveal-system, scroll-progress, contact-form, reduced-motion-fallback

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
