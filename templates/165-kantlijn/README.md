# Kantlijn — de standaard-one-pager

De universele basis als goed bijgehouden grootboek: registerrijen, schrijflijn-inputs en één moerbei-accent. In de hero klapt een mechanisch split-flap-bord tussen doelgroepen — bewijs dat dit ontwerp voor iedereen werkt.

- **Tier:** Signature
- **Sector:** Algemeen
- **Sfeer:** licht
- **Lettertypen:** Besley, Source Sans 3, Fragment Mono
- **Technieken:** split-flap-hero, count-up, pricing-toggle, quote-carousel, faq-accordion, scroll-spy, sticky-header, mobile-menu, contact-form, form-validate, reveal-system, anim-opt-in, reduced-motion-fallback

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
