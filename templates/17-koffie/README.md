# Koffiebranderij

Crème/karamel met stoom-animaties, brandgraad-meters en procestijdlijn.

- **Tier:** Premium
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Outfit, DM Mono
- **Technieken:** steam-anim, roast-meters, drawing-timeline, subscription-toggle, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
