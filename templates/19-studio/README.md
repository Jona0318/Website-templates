# Studio Kaap

Het pronkstuk: de sterkste features uit de hele galerij gebundeld in één donkere flagship.

- **Tier:** Flagship
- **Sector:** Creatief
- **Sfeer:** donker
- **Lettertypen:** Bricolage Grotesque, Instrument Serif, Inter, Space Mono
- **Technieken:** preloader, manifest-scroll, bento-grid, 3d-tilt, before-after-slider, drawing-timeline, velocity-marquee, faq-accordion, live-clock, duotone, pricing-toggle, carousel, count-up, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
