# Buitenplaats

De lichte tegenpool: serif-tuinarchitectuur met curtain-reveal en seizoenstijdlijn.

- **Tier:** Flagship
- **Sector:** Diensten
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Hanken Grotesk, IBM Plex Mono
- **Technieken:** curtain-reveal, arc-mask, before-after-slider, category-filter, drawing-timeline, duotone, faq-accordion, live-clock, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
