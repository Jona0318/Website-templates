# Letterstudio

Interactief specimen-lab met bewerkbaar reuze-proefwoord en scroll-morfend variabel font.

- **Tier:** Signature
- **Sector:** Creatief
- **Sfeer:** licht
- **Lettertypen:** Epilogue, Fraunces, Space Mono
- **Technieken:** editable-text, variable-font-slider, scroll-morph, glyph-grid, pricing-toggle, css-showcases, faq-accordion, live-clock, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
