# Museum / Kunsthal

Live “nu geopend”-status, sleepbare collectiestrook en volwaardige lightbox.

- **Tier:** Signature
- **Sector:** Cultuur
- **Sfeer:** licht
- **Lettertypen:** Syne, Newsreader, Inter, Space Mono
- **Technieken:** live-open-status, draggable-strip, lightbox, faq-accordion, pricing-toggle, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
