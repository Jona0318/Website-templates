# Sterrenwacht

Canvas-sterrenhemel, bouw-je-eigen-sterrenbeeld en een maanfase berekend uit de datum.

- **Tier:** Signature
- **Sector:** Cultuur
- **Sfeer:** donker
- **Lettertypen:** Fraunces, Space Grotesk, Space Mono
- **Technieken:** canvas-starfield, constellation-builder, moon-phase-calc, live-clock, pricing-toggle, faq-accordion, contact-form, count-up, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
