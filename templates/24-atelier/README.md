# Generatieve Studio

Live stroomveld-canvas: stuur dichtheid en turbulentie met sliders en download als PNG.

- **Tier:** Signature
- **Sector:** Creatief
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Space Grotesk, Space Mono
- **Technieken:** canvas-flowfield, palette-picker, png-export, generative-thumbnails, manifest-scroll, drawing-timeline, pricing-toggle, faq-accordion, contact-form, count-up, magnetic-button, 3d-tilt, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
