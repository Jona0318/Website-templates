# Makelaar / Vastgoed

Generator-template: diensten, uitgelicht aanbod, courtage-tarieven, FAQ en waardebepaling.

- **Tier:** Basis
- **Sector:** Diensten
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Space Grotesk, Space Mono
- **Technieken:** pricing, faq-accordion, contact-form, count-up, live-clock, split, manifest-scroll, magnetic-button, 3d-tilt, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
