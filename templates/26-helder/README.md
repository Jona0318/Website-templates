# Helder — digitale studio

Algemene studio met split-hero, zigzag-rijen, showcase en proces — violet × lime.

- **Tier:** Basis
- **Sector:** Algemeen
- **Sfeer:** licht
- **Lettertypen:** Schibsted Grotesk, Plus Jakarta Sans, JetBrains Mono
- **Technieken:** hero-split, logos, zigzag, showcase, steps, metrics, testimonials, pricing-toggle, faq-accordion, contact-form, count-up, live-clock, cta, magnetic-button, 3d-tilt, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
