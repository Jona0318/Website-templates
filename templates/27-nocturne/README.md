# Nocturne — creatieve studio

Donkere agency met center-hero, kinetische marquee, interactieve tabs en team — mint × lila.

- **Tier:** Basis
- **Sector:** Algemeen
- **Sfeer:** donker
- **Lettertypen:** Space Grotesk, Onest, Space Mono
- **Technieken:** hero-center, marquee, showcase, quote, tabs, stats, team, testimonials, pricing, faq-accordion, contact-form, count-up, live-clock, magnetic-button, 3d-tilt, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
