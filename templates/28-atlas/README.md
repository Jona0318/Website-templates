# Atlas — aanpasbare starter

Live thema-editor: kleur, modus, hoeken en lettertype live aanpassen en kopiëren als CSS.

- **Tier:** Aanpasbaar
- **Sector:** Algemeen
- **Sfeer:** licht én donker
- **Lettertypen:** Schibsted Grotesk, Plus Jakarta Sans, Fraunces, Inter, JetBrains Mono
- **Technieken:** theme-editor, live-dark-mode, accent-picker, radius-slider, font-toggle, css-export, hero-media, steps, comparison, split, metrics, pricing, faq-accordion, banner, contact-form, count-up, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
