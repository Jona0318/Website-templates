# Noorderlicht — arctische reizen

Reisbureau met een canvas-aurora die over de sterren golft — plus bestemmingen en aurora-garantie.

- **Tier:** Signature
- **Sector:** Reizen
- **Sfeer:** donker
- **Lettertypen:** Spectral, Hanken Grotesk, Space Mono
- **Technieken:** canvas-aurora, showcase, zigzag, metrics, testimonials, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
