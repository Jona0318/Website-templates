# Groef — platenlabel

Onafhankelijk label met een draaiende plaat en audiovisualizer — speel een groove en kijk mee.

- **Tier:** Signature
- **Sector:** Muziek
- **Sfeer:** donker
- **Lettertypen:** Space Grotesk, Inter, Space Mono
- **Technieken:** webaudio-visualizer, spinning-record, showcase, zigzag, metrics, team, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
