# Neonburcht — game studio

Synthwave game studio met een neon perspectief-grid en ondergaande zon, live op canvas.

- **Tier:** Signature
- **Sector:** Games
- **Sfeer:** donker
- **Lettertypen:** Orbitron, Inter, Space Mono
- **Technieken:** canvas-synthwave-grid, showcase, tabs, metrics, team, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
