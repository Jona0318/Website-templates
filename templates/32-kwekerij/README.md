# Wildgroei — stadskwekerij

Plantenwinkel waar recursieve planten voor je ogen de hero in groeien.

- **Tier:** Signature
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Hanken Grotesk, Space Mono
- **Technieken:** canvas-generative-plants, showcase, zigzag, metrics, testimonials, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
