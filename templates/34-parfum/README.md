# Sillage — geurhuis

Parfumhuis met opstijgende inkt/rook-diffusie en een interactieve geurpiramide.

- **Tier:** Signature
- **Sector:** Retail
- **Sfeer:** donker
- **Lettertypen:** Cormorant Garamond, Jost, Space Mono
- **Technieken:** canvas-smoke-diffusion, scent-pyramid, showcase, zigzag, metrics, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
