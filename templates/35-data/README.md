# Meetlat — data & dashboards

Data-consultancy met een live animerende dashboard-grafiek en KPI’s op canvas.

- **Tier:** Signature
- **Sector:** Tech
- **Sfeer:** donker
- **Lettertypen:** Space Grotesk, Inter, JetBrains Mono
- **Technieken:** canvas-live-chart, features, tabs, metrics, comparison, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
