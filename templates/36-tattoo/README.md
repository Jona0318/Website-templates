# Inktzwart — tattoo studio

Tattoo studio: teken met je cursor in zwarte en rode inkt op crèmepapier.

- **Tier:** Signature
- **Sector:** Creatief
- **Sfeer:** licht
- **Lettertypen:** Anton, Inter, Space Mono
- **Technieken:** canvas-ink-draw, interactief, showcase, steps, metrics, team, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
