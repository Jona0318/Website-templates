# Tij — surfschool

Surfschool met een gelaagde, golvende zee op canvas en een zonnige strandclub-vibe.

- **Tier:** Signature
- **Sector:** Sport
- **Sfeer:** licht
- **Lettertypen:** Bricolage Grotesque, Hanken Grotesk, Space Mono
- **Technieken:** canvas-waves, features, zigzag, metrics, testimonials, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
