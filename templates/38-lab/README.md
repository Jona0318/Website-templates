# Synaps — AI-lab

Toegepast AI-lab met een neuraal deeltjesnetwerk dat op je muis reageert.

- **Tier:** Signature
- **Sector:** Tech
- **Sfeer:** donker
- **Lettertypen:** Space Grotesk, Inter, JetBrains Mono
- **Technieken:** canvas-neural-network, interactief, features, tabs, metrics, comparison, faq-accordion, contact-form, reveal-system, anim-opt-in

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
