# Vlier — bistro & natuurwijn

Handgemaakte, redactionele restaurantsite met echte foto’s, een getypte menukaart en een live open/dicht-status — bewust géén template-look.

- **Tier:** Maatwerk
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** DM Serif Display, Spectral
- **Technieken:** editorial-layout, real-photos, typeset-menu, dotted-leaders, drop-cap, pull-quote, live-open-status, today-hours-highlight, sticky-reserve-bar, reservation-form, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
