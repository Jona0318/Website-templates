# Klaver — tandartspraktijk

Rustige, met de hand gebouwde healthcare-site: licht en luchtig, met echte foto’s, een open-status uit de openingstijden en een vriendelijk afspraakformulier.

- **Tier:** Maatwerk
- **Sector:** Gezondheid
- **Sfeer:** licht
- **Lettertypen:** Figtree
- **Technieken:** editorial-layout, real-photos, rounded-soft-ui, live-open-status, today-hours-highlight, treatment-list, plain-faq, appointment-form, sticky-header, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
