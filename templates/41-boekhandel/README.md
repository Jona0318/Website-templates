# Marginalia — boekhandel

Literaire boekhandel als krant-masthead met meerkoloms voorpagina en sticky scroll-spy inhoudsindex; tips, agenda en open-status.

- **Tier:** Maatwerk
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Newsreader, Spline Sans Mono
- **Technieken:** editorial-layout, real-photos, staff-picks-list, events-agenda, live-open-status, today-hours-highlight, newsletter-form, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
