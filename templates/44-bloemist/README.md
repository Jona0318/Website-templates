# Veld — bloemist

Botanische bloemist met gecentreerde redactionele hero en volle-breedte banden; seizoensboeketten (echte foto’s), abonnement en nieuwsbrief — salie × oudroze.

- **Tier:** Maatwerk
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Marcellus, Mulish
- **Technieken:** editorial-layout, real-photos, product-cards, subscription, live-open-status, newsletter-form, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
