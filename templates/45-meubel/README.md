# Eik & Es — meubels

Minimalistische meubelwinkel als bento-raster van ongelijke tegels met echte productfoto’s; collecties, werkplaats en showroom — neutraal × hout.

- **Tier:** Maatwerk
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Hanken Grotesk
- **Technieken:** editorial-layout, real-photos, minimal-whitespace, collections-grid, live-open-status, contact-form, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
