# Desem — bakkerij

Ambachtelijke bakkerij met utility-bar (open-status), klassieke nav en zigzag-secties; getypte kaart, ambacht-verhaal en brood bestellen — slab-serif.

- **Tier:** Maatwerk
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** Bitter, Inter
- **Technieken:** editorial-layout, real-photos, typeset-menu, dotted-leaders, live-open-status, order-form, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
