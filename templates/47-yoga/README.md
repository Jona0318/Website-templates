# Adem — yogastudio

Rustige yogastudio, minimaal en gecentreerd met veel witruimte; ademcirkel, weekrooster met vandaag-markering en proefles — zand × terracotta.

- **Tier:** Maatwerk
- **Sector:** Gezondheid
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Inter
- **Technieken:** editorial-layout, real-photos, weekly-schedule, today-highlight, pricing-list, trial-form, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
