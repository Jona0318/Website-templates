# Wrongel — kaaswinkel

Ambachtelijke kaaswinkel & affineur als katern-magazine met sticky genummerde sectie-index; assortiment per kilo, proefplank en open-status.

- **Tier:** Maatwerk
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Lora, Inter
- **Technieken:** editorial-layout, real-photos, assortment-list, tasting-board, live-open-status, order-form, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
