# Maas — fine dining

Luxe restaurant, minimaal en gecentreerd op één smalle as met didone-typografie; getypt zevengangen-proefmenu en open-status — donker × goud.

- **Tier:** Maatwerk
- **Sector:** Horeca
- **Sfeer:** donker
- **Lettertypen:** Bodoni Moda, Jost
- **Technieken:** full-bleed-hero, tasting-menu, seatings-status, reservation-form, real-photos, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
