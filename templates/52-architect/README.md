# Grond — architecten

Beton-minimalistisch architectenbureau met vaste side-rail nav (scroll-spy) naast een rustig projectraster met grote beelden.

- **Tier:** Maatwerk
- **Sector:** Creatief
- **Sfeer:** licht
- **Lettertypen:** Space Grotesk, Inter
- **Technieken:** scroll-spy-index, project-list, real-photos, stats, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
