# Tussen — koffiebar

Moderne koffiebar met schermvullende beeld-hero en overlappende kaarten (vandaag-special, open-status) over de hero-rand — cream × kobalt.

- **Tier:** Maatwerk
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** Bricolage Grotesque, Inter
- **Technieken:** day-aware-special, menu, live-open-status, newsletter, real-photos, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
