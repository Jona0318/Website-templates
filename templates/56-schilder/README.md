# Laag — schildersbedrijf

Schildersbedrijf met split-hero, side-rail nav en asymmetrisch raster; interactieve kleurkiezer die de kamer mee laat veranderen.

- **Tier:** Maatwerk
- **Sector:** Diensten
- **Sfeer:** licht
- **Lettertypen:** Hanken Grotesk, Inter
- **Technieken:** colour-picker, service-cards, steps, quote-form, real-photos, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
