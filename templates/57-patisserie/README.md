# Suiker — patisserie

Verfijnde patisserie als bento-raster met echte gebak-foto’s; assortiment, ambacht en taart-bestelformulier — rozig cream, Italiana.

- **Tier:** Maatwerk
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** Italiana, Inter
- **Technieken:** category-swatches, order-form, live-open-status, real-photos, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
