# Verte — reizen op maat

Boutique-reisbureau met full-bleed bestemmings-hero en bestemmingskaarten (echte foto’s) die over de hero-rand schuiven — groen × terracotta.

- **Tier:** Maatwerk
- **Sector:** Reizen
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Inter
- **Technieken:** full-bleed-hero, destination-cards, image-band, plan-form, real-photos, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
