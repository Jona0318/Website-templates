# Kam — kapsalon

Chique kapsalon, minimaal en gecentreerd met hairline-details; eerlijke prijslijst en boek-een-stoel — off-white × mauve, Jost.

- **Tier:** Maatwerk
- **Sector:** Diensten
- **Sfeer:** licht
- **Lettertypen:** Jost, Inter
- **Technieken:** price-list, live-open-status, booking-form, real-photos, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
