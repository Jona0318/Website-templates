# VOLT — creatief bureau

Neo-brutalistisch bureau met diagonale poster-composities, gekantelde blokken en marquee-ticker — lime × paars × zwart.

- **Tier:** Grafisch
- **Sector:** Creatief
- **Sfeer:** licht
- **Lettertypen:** Syne, Space Mono
- **Technieken:** marquee-ticker, oversized-type, rotating-sticker, hard-shadow-cards, hover-color-flip, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
