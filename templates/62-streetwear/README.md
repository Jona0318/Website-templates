# DRIFT — streetwear drop

Streetwear-drop met side-rail nav en horizontaal scrollende lookbook-strip (echte foto’s); limited-edition productgrid — kobalt × hot pink.

- **Tier:** Grafisch
- **Sector:** Mode
- **Sfeer:** licht
- **Lettertypen:** Archivo Black, Archivo, Space Mono
- **Technieken:** drop-bar, oversized-type, horizontal-lookbook-strip, product-grid, hard-shadow-cards, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
