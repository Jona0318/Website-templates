# VOLTAGE — festival

Poster-festival met gekantelde diagonale composities; line-up, dag-tabs met pijltjesnavigatie en ticket-tiers — acid-geel × zwart.

- **Tier:** Grafisch
- **Sector:** Evenement
- **Sfeer:** donker
- **Lettertypen:** Anton, Space Grotesk, Space Mono
- **Technieken:** poster-hero, lineup, marquee, day-tabs, ticket-tiers, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
