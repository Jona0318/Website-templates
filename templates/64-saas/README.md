# KERNEL — dev tool

Developer-tool als bento-mozaïek met een live-getypte console-tegel, features en prijzen — donker × cyan.

- **Tier:** Grafisch
- **Sector:** Software
- **Sfeer:** donker
- **Lettertypen:** Sora, JetBrains Mono
- **Technieken:** grid-hero, typed-console, block-feature-grid, steps, pricing, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
