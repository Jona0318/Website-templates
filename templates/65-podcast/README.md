# FREQ — podcast

Redactionele podcast met vaste side-rail incl. waveform-mini-speler; afleveringenlijst en makers — oranje × teal × cream.

- **Tier:** Grafisch
- **Sector:** Media
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Space Grotesk
- **Technieken:** player-hero, clickable-waveform, demo-player, episode-list, hosts, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
