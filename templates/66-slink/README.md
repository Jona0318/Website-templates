# Slink — cocktailbar

Atmosferische cocktailbar in de Jordaan — donker amber-goud palet, Cormorant Garamond serif en een kaart die wisselt met de seizoenen.

- **Tier:** Premium
- **Sector:** Horeca
- **Sfeer:** donker
- **Lettertypen:** Cormorant Garamond, Outfit
- **Technieken:** Dark theme, Marquee, Reserveringsformulier

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
