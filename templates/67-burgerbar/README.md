# SMASH — burgerbar

Speels-brutalistische burgerbar met utility-bar, split-hero en zigzag-menukaart met echte foodfoto’s; afhaalformulier — ketchup × mosterd.

- **Tier:** Grafisch
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** Bungee, Fredoka, Space Mono
- **Technieken:** playful-hero, rotating-sticker, marquee, menu-cards, order-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
