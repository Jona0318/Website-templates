# NOCTURN — nachtclub

Nachtclub met full-bleed donkere beeld-hero en agenda-kaarten die over de hero-rand schuiven; tafelreservering — UV-paars × acid-cyaan.

- **Tier:** Grafisch
- **Sector:** Uitgaan
- **Sfeer:** donker
- **Lettertypen:** Syncopate, Space Grotesk, Space Mono
- **Technieken:** glow-poster-hero, agenda, info-cards, table-reservation, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
