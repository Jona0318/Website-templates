# Grip — boulderhal

Modern indoor klimcentrum in krijtwit met vivid oranje-rood accent — Oswald condensed display, stats-band, prijstabel en FAQ.

- **Tier:** Premium
- **Sector:** Sport
- **Sfeer:** licht
- **Lettertypen:** Oswald, Inter
- **Technieken:** Stats-band, Prijstabel, FAQ, Contactformulier

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
