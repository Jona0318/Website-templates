# WALS — platenzaak

Retro-platenzaak met side-rail nav, draaiende-vinyl-hero en horizontaal scrollende platenbak met genre-filter — burnt orange × cream.

- **Tier:** Grafisch
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Climate Crisis, Space Grotesk, Space Mono
- **Technieken:** spinning-vinyl-hero, marquee, genre-filter, crate-grid, newsletter-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
