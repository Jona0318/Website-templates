# TEMPO — dansstudio

Kinetische dansstudio als content-hub met het weekrooster (dag-tabs, pijltjesnavigatie) als kloppend hart; stijlen — zwart × magenta × lime.

- **Tier:** Grafisch
- **Sector:** Sport
- **Sfeer:** donker
- **Lettertypen:** Familjen Grotesk, Space Mono
- **Technieken:** kinetic-hero, marquee, style-cards, day-tabs-schedule, today-auto-select, trial-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
