# HUB — co-working

Co-working als neo-brutalist bento-raster van ongelijke tegels met echte ruimtefoto’s; voorzieningen, prijzen en rondleiding — cream × chartreuse × kobalt.

- **Tier:** Grafisch
- **Sector:** Zakelijk
- **Sfeer:** licht
- **Lettertypen:** Space Grotesk, Space Mono
- **Technieken:** geometric-hero, shape-collage, space-cards, amenities-band, tour-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
