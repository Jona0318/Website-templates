# BETON — aannemer

Industriële aannemer met hazard-utilitybalk, split-hero en zigzag-projecten met echte bouwfoto’s; offerteformulier — safety-geel × zwart.

- **Tier:** Grafisch
- **Sector:** Bouw
- **Sfeer:** licht
- **Lettertypen:** Anton, Barlow, Space Mono
- **Technieken:** hazard-stripes, outline-type-hero, service-cards, project-grid, steps, quote-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
