# KOM — poké bar

Poké bar met split-hero (echte bowl-foto) en asymmetrisch raster; interactieve bowl-bouwer met live prijs — fris groen × koraal.

- **Tier:** Grafisch
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** Fredoka, Space Grotesk, Space Mono
- **Technieken:** playful-hero, bowl-illustration, interactive-bowl-builder, live-price, classics-grid, order-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
