# ROOM — ambachtelijk ijs

Speelse ijssalon met gecentreerde hero en gekleurde volle-breedte banden; smakengrid met echte ijsfoto’s en prijzenband — pastel-bold.

- **Tier:** Grafisch
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** Baloo 2, Nunito, Space Mono
- **Technieken:** playful-hero, floating-cones, marquee, flavor-grid, price-band, contact-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
