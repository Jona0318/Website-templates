# BOLT — energiedrank

Energiedrank-merk met full-bleed product-hero en overlappende stat-kaarten; CSS-blik dat live van kleur/smaak wisselt — electric blue × lime.

- **Tier:** Grafisch
- **Sector:** Product
- **Sfeer:** donker
- **Lettertypen:** Archivo Black, Archivo, Space Mono
- **Technieken:** product-hero, css-can, flavor-color-switch, stat-strip, flavor-grid, signup-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
