# WOORD — literair festival

Literair festival als magazine met sticky sectie-index (scroll-spy); asymmetrische redactionele hero, sprekers en programma — cream × diep rood, Fraunces.

- **Tier:** Grafisch
- **Sector:** Evenement
- **Sfeer:** licht
- **Lettertypen:** Fraunces, Space Grotesk, Space Mono
- **Technieken:** editorial-poster-hero, name-list, program-list, speaker-grid, ticket-tiers, newsletter-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
