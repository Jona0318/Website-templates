# Noot — muziekschool

Warme muziekschool voor alle leeftijden in crème met indigo — Lora serif, zigzag-aanpaksectie, tarieven en gratis proefles-formulier.

- **Tier:** Premium
- **Sector:** Muziek
- **Sfeer:** licht
- **Lettertypen:** Lora, Nunito
- **Technieken:** Zigzag, Metrics, Tarieven, Proefles-formulier

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
