# ONTSNAP — escape rooms

Gespannen escape rooms in poster/diagonaal met side-rail; aftelklok in de schuine hero-wig en gestaffelde room-strips — bijna-zwart × oranje.

- **Tier:** Grafisch
- **Sector:** Uitgaan
- **Sfeer:** donker
- **Lettertypen:** Oswald, Barlow, Space Mono
- **Technieken:** countdown-hero, live-clock, room-cards, difficulty-meters, booking-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
