# KROON — nagelstudio

Nagelstudio, minimaal en gecentreerd met hairline-details; echte nail-art galerij en prijslijst met dotted leaders — hot pink × goud.

- **Tier:** Grafisch
- **Sector:** Beauty
- **Sfeer:** licht
- **Lettertypen:** Syne, Manrope, Space Mono
- **Technieken:** glam-hero, rotating-crown, marquee, colorblock-gallery, price-list, booking-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
