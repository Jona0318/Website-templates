# SPRINT — running crew

Energieke running crew met side-rail, outline-type-hero en horizontaal scrollende runs-strip met pace-tags — oranje × beton.

- **Tier:** Grafisch
- **Sector:** Sport
- **Sfeer:** licht
- **Lettertypen:** Archivo Black, Archivo, Space Mono
- **Technieken:** outline-type-hero, marquee, runs-list, pace-tags, level-cards, stats-band, join-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
