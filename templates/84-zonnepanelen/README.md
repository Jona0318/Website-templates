# STROOM — zonnepanelen

Bold-eco zonnepanelen met split-hero en asymmetrisch bento; interactieve besparings-slider die kWh en euro’s live berekent — zon-geel × diep groen.

- **Tier:** Grafisch
- **Sector:** Energie
- **Sfeer:** donker
- **Lettertypen:** Space Grotesk, Space Mono
- **Technieken:** eco-hero, savings-calculator, range-slider, live-calc, stat-strip, benefit-cards, quote-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
