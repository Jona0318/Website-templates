# KLEUR — kunstgalerie

Kunstgalerie als magazine met sticky scroll-spy index; uitgelichte expo-opening en exposities met echte kunstwerk-foto’s — bold poster-typografie.

- **Tier:** Grafisch
- **Sector:** Cultuur
- **Sfeer:** licht
- **Lettertypen:** Syne, Space Grotesk, Space Mono
- **Technieken:** colorblock-hero, color-band, exposition-cards, artist-grid, visit-band, newsletter-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
