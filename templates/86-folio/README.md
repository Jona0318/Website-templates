# FOLIO — redactioneel systeem

Verfijnd Swiss-grid ontwerpsysteem (Instrument Serif): zichtbaar kolommenraster (toets G), scroll-spy index, werk-index en live klok + coördinaat. Inhoud-agnostisch — bruikbaar voor elke site.

- **Tier:** Editorieel
- **Sector:** Algemeen
- **Sfeer:** licht
- **Lettertypen:** Instrument Serif, Hanken Grotesk, Space Mono
- **Technieken:** swiss-grid, column-grid-overlay(toets G), scroll-spy-index, work-index-hover, live-amsterdam-clock, cursor-coordinate-readout, spec-column-hero, figures-band, numbered-services, colophon-form, form-validate, subtle-reveal

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
