# AMBER — jazzclub

Nachtelijk art-deco jazzclub in middernachtblauw × amber-goud × wijnrood: moody hero met live-status, programma met optredens (uitverkocht-badges), ticket-tiers, JS-openingstijden en reserveringsformulier.

- **Tier:** Grafisch
- **Sector:** Uitgaan
- **Sfeer:** donker
- **Lettertypen:** Playfair Display, Jost
- **Technieken:** live-open-status, program-list, soldout-badges, ticket-tiers, reservation-form, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
