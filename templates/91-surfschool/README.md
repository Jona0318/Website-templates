# WESTKUST — surfschool

Vibrant kust-sport surfschool in turquoise × zand × koraal: golvende wave-dividers, fake-live condities-widget (golf/wind/getij), lespakketten per niveau, reviews en boekformulier met datumkeuze.

- **Tier:** Grafisch
- **Sector:** Sport
- **Sfeer:** licht
- **Lettertypen:** Archivo, Outfit
- **Technieken:** wave-dividers, live-conditions-widget, lesson-packages, reviews, booking-form, date-picker, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
