# ENSO — izakaya

Minimalistisch zen izakaya in washi-wit × sumi-inkt × vermiljoen: Shippori Mincho-serif, verticale-tekst accenten, menu met tabs (sushi/ramen/sake), openingstijden en reserveringsformulier.

- **Tier:** Premium
- **Sector:** Horeca
- **Sfeer:** licht
- **Lettertypen:** Shippori Mincho, Zen Kaku Gothic New
- **Technieken:** vertical-text-accents, menu-tabs, live-open-status, reservation-form, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
