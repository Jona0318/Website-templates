# NOORDWAND — bergsport

Rauw-technisch outdoor- & bergsportmerk in leisteen × bosgroen × signaaloranje: topografische hoogtelijnen, Oswald-koppen, uitrusting-grid, tochten met hoogtemeters/zwaarte en inschrijfformulier.

- **Tier:** Grafisch
- **Sector:** Retail
- **Sfeer:** donker
- **Lettertypen:** Oswald, Barlow, JetBrains Mono
- **Technieken:** topographic-lines, gear-grid, tours-with-stats, difficulty-meters, signup-form, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Template Galerij](../../index.html).
