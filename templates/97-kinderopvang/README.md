# PLUK — kinderopvang

Vrolijk candy kinderdagverblijf in koraal × geel × groen × lucht-blauw op cream: blob-vormen, golf-scheidingen, kleur-gecodeerde groepen, dagritme-tijdlijn, tarieven-info en rondleidingsformulier.

- **Tier:** Grafisch
- **Sector:** Kinderopvang
- **Sfeer:** licht
- **Lettertypen:** Baloo 2, Nunito
- **Technieken:** blob-shapes, wave-dividers, color-coded-groups, daily-timeline, pricing-info, tour-form, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
