# VIZIER — optiek

Strak modern fashion-grafisch brillenboutique in wit × zwart × vivid kobalt: bold Archivo-display, filterbare monturen-collectie (rond/hoekig/zonnebril) met live count, oogmeting-service en afspraakformulier.

- **Tier:** Grafisch
- **Sector:** Retail
- **Sfeer:** licht
- **Lettertypen:** Archivo, Space Grotesk
- **Technieken:** collection-filter, live-count, category-filter, eye-test-service, booking-form, form-validate, reveal-system

## Gebruiken

Open `index.html` rechtstreeks in je browser — geen build-tools of dependencies nodig.
Een lokale server werkt ook: `python -m http.server` of `npx serve`.

Dit bestand maakt deel uit van de [Bron](../../index.html).
